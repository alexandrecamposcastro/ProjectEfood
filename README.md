# Efood

A modern food delivery frontend platform built with **React**, **TypeScript**, and **Redux Toolkit**. This project focuses on a seamless user journey, from restaurant browsing to a fully functional checkout process.

## Features

* **Restaurant Listing:** Dynamic rendering of restaurants with category filtering.
* **Menu & Modals:** Interactive product selection with detailed views.
* **Cart System:** Persistent cart management using Redux, allowing users to add/remove items and manage quantities.
* **Multi-step Checkout:** A streamlined delivery and payment form with real-time validation.
* **API Integration:** Fetches data from a backend service to populate restaurants, menus, and process orders.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.

## Tech Stack

* **Core:** React 18 & TypeScript
* **State Management:** Redux Toolkit (Slices & API Query)
* **Styling:** Styled Components (CSS-in-JS)
* **Forms & Validation:** Formik & Yup
* **Routing:** React Router DOM

## Project Structure

* `src/components/`: Reusable UI components (Header, Footer, Product Card, Cart).
* `src/pages/`: Main views (Home, Restaurant Profile).
* `src/services/`: API definitions using RTK Query for data fetching.
* `src/store/`: Redux configuration and state slices.
* `src/styles/`: Global styles and theme definitions.

## Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/alexandrecamposcastro/ProjectEfood.git](https://github.com/alexandrecamposcastro/ProjectEfood.git)
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run the development server:**
    ```bash
    npm start
    ```
